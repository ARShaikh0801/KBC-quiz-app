## 🚀 Overview

**KBC Quiz Master** is an interactive web-based quiz application that challenges your general knowledge. It features a modern, clean UI design, smooth animations, and is fully responsive—delivering a fantastic user experience across desktop, tablet, and mobile devices!

## ✨ Key Features

- **📱 Fully Responsive**: Fluid design that looks great on any screen size.
- **🎨 Modern UI**: Beautiful gradients, sleek shadows, and interactive hover states using CSS3.
- **⚡ Dynamic Rendering**: Questions and options are generated dynamically using Vanilla JavaScript.
- **🔀 Randomized Questions**: Every session feels fresh thanks to the built-in array shuffler.
- **💯 Real-time Scoring**: Tracks your score instantly and provides feedback at the end.
- **⏪ Navigation Controls**: Easily move forward and backward through the questions.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3 / Flexbox / Grid**: For a responsive, beautiful layout and micro-interactions.
- **Vanilla JavaScript**: For logic, state management, and DOM manipulation. No external dependencies!

## 🏁 Getting Started

Running this project locally is simple. No complicated build steps required!

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge).

### Installation and Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ARShaikh0801/KBC-quiz-app.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd KBC-quiz-app
   ```

3. **Run the App:**
   - Double-click `index.html` to open it directly in your browser.
   - **OR** serve it locally for the best experience:
     ```bash
     # If you have Python installed
     python -m http.server 8000
     ```
     Then, open `http://127.0.0.1:8000` in your browser.

## ⚙️ Customization

Want to make it your own? 
- Open `script.js` and modify the `questionPool` array to add your own custom questions and answers.
- Tweak the CSS variables in `:root` inside `kbc_style.css` to instantly change the entire color scheme.
